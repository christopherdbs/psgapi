## Overview

The PSGAPI is a free RESTful API that provides access to various data related to Paris Saint-Germain (PSG), including team information, player statistics, match results, and more.

## Features

- Retrieve detailed player profiles and statistics.
- Access team information.
- Get past and upcoming match details.
- Fetch the seasons and performance metrics by competition.
- Retrieve all the trophies.

## Technologies Used

- **Node.js** with **Express.js** for server-side logic.
- **MongoDB** for database storage.
- **JWT** for authentication (if implemented).

## Installation

### Prerequisites

Ensure you have the following installed on your system:

- Node.js (v16 or later)
- MongoDB (if using a local database)

### Steps

1. Clone the repository:
   ```sh
   git clone https://github.com/christopherdbs/psgapi.git
   cd psgapi
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the server:
   ```sh
   make start
   ```
